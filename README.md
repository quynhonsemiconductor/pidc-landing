# pidc-landing

Marketing site for PIDC — Pisico Data Center JSC (`pidc.vn`). Astro + Tailwind CSS v4,
static output. English (default) + Vietnamese routes land with the content PRs. Tooling
mirrors [qnsc-landing](https://github.com/quynhonsemiconductor/qnsc-landing).

## Stack

- **Astro** — static site generation (image optimization via `astro:assets` lands with the content PRs)
- **Tailwind CSS v4** — styling
- **TypeScript** — strict, `astro check` gates CI
- **Hosting** — Cloudflare Pages (separate PIDC account; deploy wiring lands later)

## Getting started

```bash
nvm use          # Node version pinned in .nvmrc
pnpm install
pnpm dev         # http://localhost:4321
```

## Search Console / Webmaster verification

Search engines are verified with an **HTML file** (no DNS change, no TXT record), so nothing in the
repository points at a Google or Bing account before the owner creates one.

1. The owner creates the property in Google Search Console (`https://www.pidc.vn/`, URL-prefix type)
   and in Bing Webmaster Tools (import from Google works), using a PIDC address, and sends the two
   filenames (`google<hash>.html`, `BingSiteAuth.xml`) with their contents.
2. Both files go in `public/` — Astro copies everything there to the site root, so they are served at
   `https://www.pidc.vn/<filename>` with no route, no rewrite and no `_headers` entry.
3. Verify in each property, then submit `https://www.pidc.vn/sitemap-index.xml` in both consoles
   (the sitemap is generated by `@astrojs/sitemap`; `sitemap-index.xml` is the entry point).
4. The verification files are public by design and safe to commit. Do not add `robots.txt` rules that
   exclude them.
