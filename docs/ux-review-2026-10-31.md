## Owner questions (need a decision, not a fix)

**Q1 — Section rhythm.** Current: 64 px band padding at ≥57.5em, plus the hero's own 64 px, giving
~150 px before each section title. Option A (current) keeps the drawing-sheet calm but reads as drift
when a section is short. Option B tightens band padding to 48 px at ≥57.5em (~30% less white, same
grid). Recommendation: B for the inner pages, A on the home hero. Screenshot of A: `01-…`,
`04-aidc-hero-1440-after.jpg`; B can be captured on request — it is a one-token change.

**Q2 — AIDC hero figure.** A (this PR): the rack sits beside the copy. B: keep it full-width in a band
under the copy, as it was before this PR (`04-aidc-hero-1440-before.jpg`), which leaves the row empty
but gives the drawing more room. Recommendation: A.

**Q3 — Location map / terrain.** Both read as tall panels with the drawing floating in the middle.
Redrawing them at ~16:9 would remove most of the empty page height. This is design time, not a layout
fix; say the word and it is its own PR.

**Q4 — Contact page audience list.** #15 removed the non-functional "I am a" radios. If the chairman
wants the three audiences (capital partners / AI compute tenants / engineering & government) back on
the page, they should return as a static list under the email — not as form controls. No new copy
needed: the three descriptions already exist in the dictionary history.

**Q5 — Phone number.** Neither the site nor the reference site carries one, so none is shown. If PIDC
wants a phone on the contact page and in the footer, send the number (and whose it is).
